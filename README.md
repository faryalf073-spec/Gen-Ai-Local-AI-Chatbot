# Streamlit Interface for Locally Hosted LLM

## Project Overview

This project develops a simple and interactive **Streamlit web interface** for interacting with a locally hosted Large Language Model (LLM).

The application uses **Ollama** as the local LLM backend and **Llama 3.2 3B** as the language model. Users can enter questions through the Streamlit interface and receive AI-generated responses directly from the locally running model.

The application also includes **conversation history** and a **reset conversation** feature to improve usability.

## Objectives

* Create a user-friendly interface for local LLM inference.
* Connect Streamlit with Ollama through a local API.
* Run Llama 3.2 3B locally.
* Allow users to submit natural-language queries.
* Display AI-generated responses.
* Maintain conversation history.
* Provide a reset option for starting a new conversation.

## System Architecture

The application follows this workflow:

```text
User
  ↓
Streamlit Web Interface
  ↓
Ollama Local API
  ↓
Llama 3.2 3B
  ↓
Generated Response
  ↓
Streamlit Interface
```

## Features

### 1. User Query Input

Users can enter questions or instructions through the chat input area.

### 2. Local LLM Inference

The application sends the user's query to the locally hosted Llama 3.2 3B model through Ollama.

### 3. AI Response Display

The generated response is returned from Ollama and displayed directly in the Streamlit interface.

### 4. Conversation History

Previous user queries and AI responses are maintained during the current session.

### 5. Reset Conversation

A reset button allows users to clear the current conversation and start a new session.

### 6. Local Processing

The LLM runs locally through Ollama, allowing inference without depending on an external cloud-based LLM API.

## Running the Application

First, make sure Ollama is running and the Llama 3.2 3B model is available.

Open Anaconda Prompt and navigate to the project directory.

Then launch the Streamlit application.

After Streamlit starts, open the provided local address in a web browser.

The application will then display the local LLM chat interface.
